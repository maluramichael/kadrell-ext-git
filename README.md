# kadrell-ext-git

Kadrell extension: clone remote repositories (GitHub, Bitbucket, your own git URLs) straight from the new-session dialog. Configure tokens, orgs and the clone folder in the extension settings.

## Install

Inside [Kadrell](https://kadrell.malura.de), press `F4`, search under "Discover" for `kadrell-ext-git` and click Install.

Or clone it by hand:

```bash
git clone https://github.com/maluramichael/kadrell-ext-git ~/.config/kadrell/extensions/git
```

Then enable it in the `F4` dialog.
